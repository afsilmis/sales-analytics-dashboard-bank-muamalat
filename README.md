# Bank Muamalat - BI Analyst Virtual Internship Experience

## Project Description
Comprehensive sales performance analysis and strategic recommendations for PT Sejahtera Bersama. This project involves building a unified data infrastructure, creating interactive dashboards, and delivering actionable business insights to optimize revenue and operational efficiency.

## Company Profile
**PT Sejahtera Bersama** - A retail company specializing in Robots, Drones, and Digital Products (eBooks & Training Videos)

## Business Objectives
- Build a solid data foundation by integrating multiple data sources
- Develop an interactive dashboard to monitor key sales metrics
- Provide data-driven recommendations to increase sales performance

## Tech Stack
- **Data Processing:** SQL
- **Visualization:** Looker Studio
- **Analysis:** Data Analysis & Business Intelligence

## Key Deliverables
1. Database schema design with primary keys & relationships
2. Master table creation (8 fields, sorted by transaction date)
3. Interactive sales dashboard with 7+ key metrics
4. Strategic business recommendations based on data insights
